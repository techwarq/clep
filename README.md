# clep — Drop any document. Get a clean spreadsheet.

Next.js (App Router) landing page + live demo widget. Deployable to Vercel with zero config.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this folder to GitHub
2. Import the repo in Vercel → Framework preset: **Next.js** → Deploy

No env vars required. `next.config.mjs` is already Vercel-ready.
